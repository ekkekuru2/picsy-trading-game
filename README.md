# picsy-trading-game

「なめらかな社会とその敵」で提案されている伝播投資通貨PICSYを、本文第3章で紹介されているように貿易ゲームの形でデモンストレーションするためのソフトウェア

## 使い方

```sh
nix develop            # numpy の入った環境に入る
python src/main.py     # 対話的に設定を聞いてから始める

python src/main.py --picsy                    # PICSY ですぐ始める
python src/main.py --secsy                    # SECSY(通常の決済貨幣)で始める
python src/main.py --picsy --gamma=0.2        # 自然回収率 γ を指定する
python src/main.py --picsy --strict-market    # 市場役にも購買力の制約をかける
```

モデルが第4章の数式どおりかどうかは、次で確かめられる。

```sh
python tests/test_model.py
```

## ゲームの進めかた

ゲームマスターが1台のPCでこのツールを動かし、参加者(国)の交渉がまとまる
たびにコマンドを打ち込んでいく。

```
[取引0回] > 取引 A C 300 紙5枚とはさみ   A が C に300ドル払う(メモつき)
[取引1回] > 買取 A 円 3                 市場が A から円3つを買い取る
[取引2回] > 比較                        PICSY効果あり/なしのランキング(図3.9)
```

`ヘルプ` でコマンド一覧、`状態` で全員のお金、`行列` で評価行列と貢献度
ベクトル、`配布物` で各国に配る物の一覧が見られる。

### このソフトが追うのはお金と評価行列だけ

紙もはさみもワークショップでは机の上に実物がある。誰が何をもっているかは
参加者が見ればわかるので、ソフトが在庫を検査すると、机の実態とずれたときに
現実のほうを邪魔することになる。だから記録するのは

- 誰が誰にいくら払ったか(何を売り買いしたかは任意のメモ)
- 市場が何をいくらで買い取ったか

だけにしてある。配る物の一覧は準備のための参考として持っているだけで、
生産できるかどうかの判定はしない。

### 自然回収のタイミング

本文では自然回収は「1日に1回とか1時間に1回といった頻度で自動的に行われる」
(4.4.2項)とあるが、90分のワークショップに「日」はない。そこで取引の回数を
時計のかわりにして、既定では**取引3回ごとに自動**で起こす。0を指定すると
手動のみになり、好きなときに起こして効果を見せられる。

### 各国に配る物(表3.1)

| 国 | タイプ | 初期のアイテム |
|----|--------|----------------|
| A, B | 先進国 | はさみ2, 紙1, ものさし, 三角定規, ペン2, コンパス2, 500ドル |
| C, D | 途上国 | 紙20, ペン, ものさし, 500ドル |
| E, F | 最貧国 | 紙1, ペン, 500ドル |

### 財と市場価格(図3.7)

| 財 | 市場価格 | 必要な道具 | 資源 |
|----|---------|-----------|------|
| 円(13cm) | $80 | コンパス, ペン, はさみ | 紙1枚 |
| 三角形(9cm) | $50 | 三角定規, ペン, はさみ | 紙1枚 |
| 四角形(7×13cm) | $40 | ものさし, ペン, はさみ | 紙1枚 |

はさみをもつのは先進国だけ、紙をたくさんもつのは途上国だけなので、
**貿易をしないとどの国も財をつくれない**。これが本文のいう貿易のパレート
優位性の体験にあたる。この分かれ方を作るのは実際に配る物であって、
ソフトではない。

市場価格は本文のとおりゲームマスターが途中で変更できる(`価格 円 120`)。

## PICSY のモデル

第4章 4.4節の**中央銀行法**を実装している(`src/picsy.py`)。

- 評価行列 `E` は `(N+1)×(N+1)`。インデックス0が中央銀行で、
  `E_ii = 0`(式4.34)、`E_0i = 1/N`(式4.35, ソーシャルミニマム)。
- 予算制約は `E_i0`。最初は全員 `E_i0 = 1` で、貢献度は `c_i = 1`、
  中央銀行の貢献度は `c_0 = N` になる。
- 貢献度ベクトル `c` は `cE = c` を満たす左固有ベクトルで、
  メンバーの貢献度の和が `N` になるように正規化する(式4.3-4.6)。
- 取引: `E_b0 -= α`, `E_bs += α`(式4.36, 4.37)。
- 自然回収: `E_bj *= (1-γ)`, `E_b0 += γ(1-E_b0)`(式4.38, 4.39)。
- 定価 `δ = α c_b`、購買力 `= E_b0 c_b`(式4.40-4.43)。

画面上の「お金」は購買力のことで、購買力1を500ドルとして表示している
(表3.1の初期所持金に合わせてある)。

### 知っておくとよいこと

- **貢献度の総和は常に N** に正規化されている。だから伝播の効果は、
  お金の絶対額ではなく「取引に関わっていない国との差」として現れる。
  `比較` コマンドの PICSY効果あり/なしの順位の違いがいちばんわかりやすい。
- 表4.2 の「取引の前後で買い手の貢献度が変わらない」は、式(4.43)の
  `c_b^{t+1} ≒ c_b^t` という**仮定**の上での話で、厳密には少し動く。
  ずれは人数 N に反比例して小さくなる(N=5 で約2%、N=100 で約0.1%)。
  `tests/test_model.py` でこの収束を確かめている。
- **市場の初期資金**には仕掛けがある。購買力は `E_i0 × c_i` で、行和が1である
  以上 `E_i0` は1を超えられない。つまり1人分の席では、市場はどうやっても
  500ドルからしか始められず、財を数個買ったら止まってしまう。
  そこで市場は行列のなかで**複数の席**を占めることにした(既定10席)。
  各席はふつうのメンバーとして1席=500ドルの購買力をもち、評価も自然回収も
  他と同じように働く。市場は 席数×500ドル から始められ、表3.1の
  「どの国も500ドル」もそのまま保たれる。SECSY の市場も同額にしてあるので、
  2つの貨幣システムを公平に比べられる。
- 評価行列の表示では、市場の席を貢献度で重みづけして1行にまとめている
  (まとめても行和は1のまま)。
- それでも市場の購買力が尽きたときは、必要な分だけ自然回収を前倒しして
  補う(`ensure_budget`)。通常の自然回収と同じ操作なので行和は1のまま、
  過去の評価も比率を保って残る。これを止めるには `--strict-market`。

## ファイル構成

| ファイル | 内容 |
|---------|------|
| `src/picsy.py` | 評価行列・貢献度ベクトル・取引・自然回収(第4章のモデル) |
| `src/currency.py` | PICSY と SECSY を同じインターフェイスで扱う |
| `src/game.py` | 国・道具・資源・生産・市場といった貿易ゲームの状態 |
| `src/main.py` | コマンドラインのゲームマスター用画面 |
| `tests/test_model.py` | モデルが第4章の性質を満たすかの確認 |
